# Ticket outline — Adviser Board filter rework

Why: `/smh-adviser-board` still runs the team/caucus architecture — one subagent per team of 3 minds,
5 hidden debate cycles, one ~250-word card per team — so the collision the chair most wants to see
happens inside a sealed sub-chat and reaches him only as a summary of a summary. The approved rework
(plan below) makes one filter = one mind = one subagent, with four visible rounds (R1 READ / R2 ATTACK
/ R3 BALCONY / R4 SETTLE) and a Round-0 cast menu of top-3 mind picks per filter.

## Plan

- [ ] (a) Round-0 cast menu: dry-run session renders top-3 mind picks per seated filter (one line each on the angle on THIS topic) + cut lines for refused filters; picks seat exactly one mind per filter
- [ ] (b) Four visible rounds: full session renders R1 READ / R2 ATTACK / R3 BALCONY / R4 SETTLE, one verbatim statement per filter (~250-word ceiling), no hidden caucus spawns
- [ ] (c) Vocabulary grep gate: zero unjustified hits for `triad`, `caucus`, `stage room`, `stage change`, `default triad`, `three minds`, `team` over the command brain + `adviser-board/` folder (excl. `minds/`) + `.agents/workflows/smh-adviser-board.md`; `floor` adjudicated per plan §8.2
- [ ] (d) Door parity: `/smh-sync-agents` leaves `.claude/skills/smh-adviser-board/` and `.opencode/commands/smh-adviser-board.md` byte-consistent with the command body; AG launcher description within the ~135-char menu budget
