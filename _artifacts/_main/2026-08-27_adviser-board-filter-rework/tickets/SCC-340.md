# Ticket outline — Adviser Board filter rework

5 hidden debate cycles, one ~250-word card per team — so the collision the chair most wants to see
happens inside a sealed sub-chat and reaches him only as a summary of a summary. The approved rework
(plan below) makes one filter = one mind = one subagent, with a Round-0 cast menu of top-3 mind picks
per filter. (As amended mid-session 2026-08-28 — see plan §11b: the original four-round ladder was
replaced by parallel opinion waves with chair-invoked deepening moves.)
