## The defect

`/smh-sync-agents` publishes each command brain to four doors. SCC-77 landed on `main` **without**
running it, so `.opencode/commands/` and `.agents/workflows/` carried the **pre-token merge steps**

**Nothing in the gate saw it.** SCC-77's close-out reported a fully green floor.

### ⚠ Correcting the attribution I shipped

## The fix — one check, and the reason it is exactly one

A door is one of two things, and the distinction is already load-bearing in `sync-agents.ps1`:

| Door kind | When | Contract |
|---|---|---|
| **full mirror** | body under the 12k Antigravity cap | **byte-identical** to `.agents/commands/<name>.md` |
| **thin launcher** | body over 11.5 KB, or a skill door | carries `GENERATED by sync-agents`, points at the brain, deliberately ~1 KB |

Verified on current `main`:

```
IDENTICAL  .opencode/commands/cicd-push-e2e.md
IDENTICAL  .agents/workflows/cicd-push-e2e.md
IDENTICAL  .opencode/commands/smh-quick-dev.md
DIFFERS    .agents/workflows/smh-quick-dev.md (1043 vs 15745)   <- launcher, correctly exempt
```

So the check is: **every full mirror is byte-identical to its brain; every non-identical door must
carry the launcher marker.** Both halves, because "exempt if it differs" is a gate that cannot fail.
