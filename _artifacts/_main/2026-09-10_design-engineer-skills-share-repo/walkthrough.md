# Walkthrough — `/smh-designer` shipped as a standalone public repo

**Date:** 2026-09-10 · **Deliverable:** <https://github.com/sudomadhatter/design-engineer-skills> (public)
**Commit:** `9348dd6` · **Plan:** [implementation_plan.md](implementation_plan.md)

## What shipped

A portable, harness-agnostic skill pack — 46 files, 7,380 lines — that stands up the whole
`/smh-designer` workflow from a git URL alone. The command centre's own copies were **read only**;
nothing here was modified.

## The edge map (what the investigation found)

`/smh-designer` is not one file. It is a command body, a generated thin launcher, eight skills and a
procedural manual, and three of its edges were invisible or broken for anyone outside this machine:

| Gap | Finding | Resolution |
|---|---|---|
| **A** | The command file names **four** pillars; the design guide names **five**. `animate-expo` and `write-swift` were reachable ONLY through the guide. Packaging from the command file alone ships a set with two missing limbs. | Command file's pillar list extended to five in the shared copy. |
| **B** | Phase 2 minted Jira via `acli` and handed off to `/smh-quick-dev`, `/smh-quick-fix`, `/cicd-dev-story-tests`, `/cicd-quick-dev` — none of which exist for a recipient. | Operator's call: Phase 2 now ends at an approved `implementation_plan.md` and stops. Hand-off demoted to a documented, optional *Adapting to your own lane* section. |
| **C** | Seven `file:///home/dlohn/Sudo_Hatter_Command/…` links in the command body; ten `../../.agents/…` links in the guide. All dead off this disk. | Rewritten repo-relative. |
| **D** | Public repo, but `emil-design-eng` encodes Emil Kowalski's craft, `vgpu` wraps `vercel-labs/vgpu`, `visual-fx-3d` wraps Poimandres. | MIT `LICENSE` scoped to the composition + `CREDITS.md` naming all three upstreams, with a takedown line. |

Also neutralised: 9 × "Mr. Hatter", the "Sudo Hatter command center" persona line, and the launcher's
"GENERATED by sync-agents; do not edit" header (meaningless without the sync tooling). Two
`__pycache__/*.pyc` files were excluded and are now `.gitignore`d.

## Repo shape

Flat `commands/` + `skills/` + `docs/` rather than `.agents/`, so the tree is legible in GitHub's file
browser. The README's **Setup** block is written as direct instructions to the *installing agent* —
clone, run `verify.py`, find the harness's skill and command directories, copy, confirm — which is
what makes "here's a URL" sufficient.
