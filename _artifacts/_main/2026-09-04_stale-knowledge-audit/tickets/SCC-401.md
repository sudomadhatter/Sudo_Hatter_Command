Why: The memory store holds 147 files that agents load every session and treat as fact, and nothing in the suite can tell one that is still true from one that stopped being true in August. That is the actual defect - not any single stale file. `two-machines-mac-and-pc.md` was confirmed 2026-08-08, went false when SCC-376 moved the environment to WSL2/Ubuntu on 2026-09-02, and stayed loaded and trusted for two more days while an agent used it to make four wrong statements to the operator in one afternoon. `memory_audit.py` today flags memories by AGE and by shape, which cannot separate an old fact that is still true from a recent one that just broke. The fix is to make a factual memory carry its own falsifier: a one-line shell command, exit 0 means still true, run by the suite. A memory that asserts a path, a binary, a version or a count can then go RED the day it stops being true, and stale knowledge stops being something the operator discovers by being told something false.
