## The new gate contract (master: `.agents/commands/sudo-dev-story-tests.md` Step 2)

- Gate message: ALWAYS the clickable `implementation_plan.md` link + two lines —
  **1.** `continue` — audit runs here · or switch your model first, then say `changed`
  **2.** handoff to another team — paste the audit file's path when it's done.
- **`continue`** → audit here on the current model, persist + fold, straight on — **no second gate**.
- **`changed`** → operator already switched the model; audit on it, persist + fold, then **STOP AGAIN**
  ("Audit done — switch back, then say `continue`"). Switch-back gate exists ONLY after `changed`.
  Never implement on the audit-switched model.
- **Pasted file path** → another team ran the audit blind (often a different LLM); copy into
  `ARTIFACT_DIR` as `self-audit-stress-test.md` if elsewhere, fold, proceed.
- Explicit "skip the audit" → confirm once, stub artifact, proceed (unchanged fallback).
- Removed: "name a model / spawn the audit as a subagent with a model override" — never offer model changes.
