Why: Claude pings the operator when a turn needs him — a Mac desktop notification plus an ntfy push
to the mac-sudo-command topic, wired through Claude Code hooks. Zoo Code has no equivalent, so its
approval asks sit unseen until the operator happens to look at the window, which is exactly the
babysitting SCC-352 exists to end. This lane gives Zoo the same two signals on both machines, so a
Zoo run that needs a decision reaches the operator the way a Claude run already does.
