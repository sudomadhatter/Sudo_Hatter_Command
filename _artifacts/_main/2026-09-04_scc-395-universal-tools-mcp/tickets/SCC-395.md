Why: External tools and software connections (Jira, Sentry, Firebase, Playwright, MD Feedback, Keyway, Cloud APIs) are currently fragmented across five agent platforms (Claude Code, Zoo Code in VS Code, OpenCode, Antigravity, Codex) and two operating systems (Mac and PC/WSL). Each platform maintains its own siloed configuration: OpenCode ignores `.opencode/mcp.json` because it requires an `mcp` stanza in `opencode.json`; Zoo Code has empty MCP settings; Claude Code carries machine-specific hardcoded paths in `.mcp.json`; and agents have no shared registry telling them whether to reach for a CLI tool or an MCP server. As a result, agents frequently hallucinate missing integrations, guess CLI flags, or corrupt files like annotated markdown that require specialized MCP servers. Sudo_Hatter_Command needs a single source of authorship for tools and connections that automatically renders platform configs and gives every agent an intent-triggered discovery skill.
